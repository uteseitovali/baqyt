# Bagyt — персональный маршрут поступления

**LOCUS Startup Hackathon 2026 · Кейс 02 · код сабмита `LOCUSCASE2`**

Bagyt превращает короткую анкету абитуриента в разбор профиля, объяснённые
рекомендации программ и пошаговый план до подачи документов.

> **Bagyt** (каз. *бағыт*) — направление, курс движения.

---

## 1. Задача

Поступление состоит из десятков решений: направление, страна, университет,
экзамены, документы, дедлайны, активности. Информация разрознена по десяткам
сайтов, рекомендации обычно слишком общие, а абитуриент не понимает главного:
**что подходит именно ему и какое действие выполнить прямо сейчас.**

Существующие решения дают либо каталог вузов, либо чат, который отвечает
правдоподобно, но непроверяемо. Ни то, ни другое не доводит человека до подачи.

## 2. Решение

Сквозной путь из семи экранов, где каждый следующий шаг вытекает из предыдущего:

| Этап | Экран | Что получает пользователь |
| --- | --- | --- |
| 1 | `/` | Ценность сервиса и ожидаемый результат за 15 секунд |
| 2 | `/profile` | Анкета из 5 коротких шагов, адаптированная под учебный трек |
| 3 | `/diagnosis` | Резюме профиля: сильные стороны, пробелы, образовательная цель |
| 4 | `/matches` | Программы с разбором по семи факторам и живой перенастройкой |
| 5 | `/compare` | Таблица различий с подсветкой лучшего значения в строке |
| 6 | `/roadmap` | План: экзамены, документы, эссе, подача — с ориентирами по срокам |
| 7 | `/roadmap#next` | Один выделенный ближайший шаг и отметка прогресса |

### Три решения, которые отличают Bagyt

**1. Ранжирование детерминированное, объяснение — от AI.**
Какой университет выше в списке, решает не языковая модель, а прозрачный
движок из семи взвешенных факторов. LLM получает уже посчитанный разбор и
только переписывает его живым языком. Поэтому каждую цифру в интерфейсе можно
проследить до конкретного правила, выдача воспроизводима, а демо не зависит от
доступности внешнего API.

**2. Реакция на изменение вводных — мгновенная.**
Панель «Живая настройка» прямо на экране рекомендаций меняет бюджет, страны,
направления и баллы. Пересчёт выполняется синхронно в браузере теми же чистыми
функциями домена, что работают на сервере, — без сетевого запроса и задержки.

**3. Честность вместо выдуманной точности.**
Вместо «вероятность поступления 73%» — категориальные полосы
**надёжный / целевой / амбициозный**, построенные на сравнении баллов
пользователя с опубликованными требованиями. Рядом с каждой цифрой — ссылка на
первоисточник и пометка о происхождении данных. Продукт нигде не обещает
поступление.

## 3. Стек

| Слой | Технология | Почему так |
| --- | --- | --- |
| Фреймворк | Next.js 16 (App Router) + React 19 | один деплой на фронт и API, SSR из коробки |
| Язык | TypeScript (strict) | доменные типы — единый контракт между API и UI |
| Стили | Tailwind CSS v4 | токены дизайн-системы заданы в CSS, тёмная тема без дублирования |
| Состояние | Zustand + persist | путь переживает перезагрузку; интерфейс хранилища узкий и заменяемый |
| Валидация | Zod | ни один невалидный профиль не доходит до доменной логики |
| Анимация | Motion | перестроение списка при пересчёте |
| Шрифты | Fontsource (self-hosted) | ноль обращений к внешним CDN в рантайме |
| Тесты | node:test + tsx | 29 тестов доменного слоя |

### Ключевой принцип

`src/lib/domain` не импортирует ни React, ни Next, ни сеть. Это чистые функции,
которые одинаково выполняются на сервере (в API-роутах) и в браузере (для
мгновенного пересчёта). Отсюда — тестируемость и одинаковый результат в обоих
местах.

### Движок подбора

Семь факторов с весами, сумма весов равна единице:

| Фактор | Вес | Что сравнивает |
| --- | --- | --- |
| Направление | 22% | профиль программы против выбранных интересов |
| Академика | 20% | баллы пользователя против опубликованных требований |
| Бюджет | 18% | стоимость года против потолка с учётом стипендий |
| Язык | 14% | языковой порог против теста или самооценки |
| География | 12% | страна и предпочтение остаться ближе к дому |
| Сроки | 8% | месяцы до дедлайна против необходимой подготовки |
| Условия | 6% | общежитие, формат кампуса |

Каждый фактор возвращает не только число, но и **человекочитаемое объяснение**,
которое попадает прямо в карточку. Полоса поступления определяется академическим
фактором с поправкой на известность программы.

**Добор полос.** Сильные, но дорогие программы проседают по бюджетному фактору и
вылетают из окна выдачи целиком — в результате абитуриент не видит ни одного
амбициозного варианта. Движок отслеживает это и добирает недостающие полосы
лучшими кандидатами из полного ранжирования, отдавая приоритет странам, которые
человек сам выбрал.

### Генератор маршрута

План строится обратным ходом от окна подачи программы. Состав задач зависит от
того, чего не хватает **в этом конкретном профиле**: если IELTS уже сдан, блок
подготовки к нему не появляется вовсе; если нужна стипендия — добавляется
отдельная задача с более ранним сроком.


### Переменные окружения

**Приложение полностью работает без единой переменной окружения.** AI подключается
только для того, чтобы переписать формулировки живым языком; при его отсутствии
интерфейс честно показывает «текст собран правилами».

Чтобы включить AI, скопируйте `.env.example` в `.env.local`:

```bash
AI_API_KEY=sk-...
AI_BASE_URL=https://api.openai.com/v1   # или Groq / OpenRouter / Ollama
AI_MODEL=gpt-4o-mini
AI_TIMEOUT_MS=12000
```

Клиент работает с любым провайдером, совместимым с OpenAI `/chat/completions`.

## 6. Тестовый сценарий для жюри

Полный путь занимает около 3 минут. На главной есть кнопка
**«Посмотреть на демо-профиле»** — она заполняет анкету за вас и открывает
результат сразу, если хочется пропустить заполнение.

1. **Пройдите путь целиком.** `/` → «Начать за 5 минут» → пять шагов анкеты →
   разбор профиля → рекомендации → сравнение → маршрут.
2. **Проверьте объяснимость.** На любой карточке раскройте
   «Разбор по семи факторам»: видно вес каждого фактора, его оценку и словесное
   обоснование с вашими собственными цифрами.
3. **Проверьте реакцию на изменение вводных.** На экране `/matches` откройте
   «Живую настройку» и:
   - опустите бюджет до минимума — дорогие программы уйдут вниз, у части
     появится пометка о серьёзном несовпадении;
   - снимите IELTS («нет теста») — языковой фактор просядет, а в маршруте
     появятся три новые задачи по подготовке к экзамену;
   - смените страны — топ выдачи перестроится полностью;
   - включите «Хочу остаться ближе к дому» — казахстанские программы поднимутся.

   Список пересчитывается мгновенно, без перезагрузки.
4. **Проверьте маршрут.** Постройте план по любой программе, отметьте ближайший
   шаг выполненным — прогресс и блок «Следующий шаг» сдвинутся на следующую
   задачу.
5. **Проверьте состояния.** Отфильтруйте выдачу так, чтобы ничего не осталось —
   появится пустое состояние с подсказкой, что ослабить. Перейдите на
   `/compare` без отмеченных вариантов — экран объяснит, что делать.
6. **Проверьте мобильную версию** и переключатель темы в шапке.
7. **Проверьте API напрямую:** `GET /api/health` показывает размер каталога и
   включён ли AI.

## 7. Данные и источники

Каталог содержит **38 программ в 10 странах** (`src/lib/data/programs.ts`):
Казахстан, Великобритания, Турция, ОАЭ, Южная Корея, Нидерланды, Чехия, Польша,
Гонконг, Малайзия.

**Честно о происхождении данных.** Каталог — кураторский демонстрационный срез,
собранный вручную по официальным страницам приёма. Требования, стоимость и даты
подачи меняются каждый приёмный цикл, поэтому:

- каждая запись несёт ссылку на первоисточник и дату фиксации;
- все записи помечены `dataConfidence: "demo"` — «ориентир, требует подтверждения»;
- интерфейс показывает эту пометку рядом с цифрами, а не прячет её;
- продукт нигде не подаёт эти значения как актуальные на сегодня и не выдаёт
  неподтверждённые дедлайны за официальные.

Замена каталога на живой источник (API вуза, база данных, парсер) выполняется
подменой одного модуля: и UI, и движок работают с типом `Program`, а не с этим
файлом.

Ориентиры по датам в маршруте выводятся из окна подачи программы и явно
подписаны как ориентиры.

## 8. AI и внешние сервисы

| Что | Где | Роль |
| --- | --- | --- |
| LLM (OpenAI-совместимый) | `src/lib/ai/` | переписывает готовый разбор живым языком |
| Внешние API | — | не используются |
| Базы данных | — | состояние в localStorage |

**Что LLM делает:** переписывает `headline`, `summary` и `goal` диагностики;
формулирует связный абзац «почему подходит» по кнопке «Объяснить словами».

**Что LLM не делает:** не решает порядок выдачи, не придумывает баллы, стоимость
и дедлайны, не формирует списки сильных сторон и пробелов.

**Защита от галлюцинаций:**

- ответ модели валидируется Zod-схемой; не прошедший валидацию ответ отбрасывается;
- `programId` из ответа сверяется с реально запрошенными — выдуманные id игнорируются;
- системный промпт запрещает добавлять цифры, даты и названия, которых не было во входных данных;
- таймаут 12 секунд, после которого отдаётся детерминированный текст;
- **любой сбой возвращает исходный текст, собранный правилами** — сценарий не прерывается.

Поле `generatedBy` в ответе API и пометка в интерфейсе всегда показывают, чем
сформулирован текст: `llm` или `rules`.

## 9. Готовые компоненты и библиотеки

UI-кит не использовался: все компоненты интерфейса (`src/components/ui/`),
дизайн-система, иконки и разметка написаны с нуля в рамках хакатона.

Внешние зависимости и их роль:

| Пакет | Роль |
| --- | --- |
| `next`, `react`, `react-dom` | фреймворк |
| `tailwindcss` | утилитарные стили, токены заданы в `globals.css` вручную |
| `zustand` | хранилище состояния пути |
| `zod` | валидация входа API и ответов LLM |
| `motion` | анимация перестроения списка |
| `clsx`, `tailwind-merge` | склейка классов |
| `@fontsource-variable/*` | self-hosted шрифты Manrope и JetBrains Mono |
| `tsx` (dev) | запуск тестов на TypeScript |
| `playwright` (dev) | скриншоты экранов при разработке |

Дизайн и структура интерфейса оригинальные и не копируют LOCUS или другую
существующую платформу.

## 10. Ограничения текущей версии

Честный список того, что не сделано, и почему:

- **Каталог статичный.** 38 программ, собранных вручную. Для продакшена нужен
  регулярно обновляемый источник — интерфейс к этому готов, ограничение в данных,
  а не в архитектуре.
- **Состояние только локальное.** Нет аккаунтов и синхронизации между
  устройствами: путь хранится в localStorage браузера. Интерфейс хранилища
  намеренно узкий, чтобы подменить его на серверный репозиторий.
- **Оценка полосы приблизительная.** Она строится на опубликованных минимальных
  требованиях и не учитывает конкурс текущего года, качество эссе и
  внеучебную часть. Именно поэтому полоса категориальная, а не процентная.
- **Только бакалавриат.** Магистратура и колледжи вне рамок кейса.
- **Одна языковая версия.** Интерфейс на русском; казахская и английская версии
  требуют слоя локализации, который пока не заложен.
- **Стипендии не детализированы.** Показывается факт наличия и примечание вуза,
  без сумм и условий отбора.
